# NOTES

## Purpose and Scope  [2026-08-02]

This document records design decisions and implementation rationale for the
`calculus` package. It is intended as a long-term memory of why certain choices
were made.

Notes are annotated with dates using the format [YYYY-MM-DD]. Once a note is
committed, it should not be modified unless it contains a fatal error. New
decisions should be recorded as new dated entries rather than by rewriting
previous ones.
